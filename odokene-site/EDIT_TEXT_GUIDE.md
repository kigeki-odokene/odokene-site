# ODOKENE 文章の編集（簡単ガイド）

公開後は `/admin/` にログインして **サイト管理 → 文章の編集（全ページ）** を開いてください。

| 書き換えたい部分 | 管理画面の項目 |
| --- | --- |
| 最初の説明文 | トップページ → 冒頭の説明 1 / 2 |
| サービス説明 | MIXの内容 → ページ冒頭の説明 |
| 料金の補足 | 料金ページの説明文 |
| 作品一覧の前置き | 制作実績ページの説明文 |
| 依頼ステップの文章 | 依頼の流れ → 依頼の流れ（詳細ページ） |
| プロフィール | ABOUTページ |
| よくある質問 | よくある質問・注意事項 → 質問と回答 |
| フォームの説明 | 依頼フォームの案内文 |

文章の変更にHTMLやCSSの知識は不要です。保存後GitHub経由で自動反映されます。なおDecap CMSのログインは未設定なので、GitHub/OAuthの初期設定完了後に利用できます。

管理画面を使う前に編集したい場合は `src/data/copy.json` を編集してください。JSONのカンマや括弧を消さないように注意してください。

**金額や納期の変更は、文章の編集画面だけでは完結しません**。料金・見積もり計算の整合性を別途確認してください。
